# سوقي | Souqi — المراحل 1 إلى 3

متجر إلكتروني (Next.js 14 App Router + TypeScript + Tailwind + Framer Motion + Zustand).
المرحلة 1 تشمل: الهيكل، عربي RTL / إنجليزي LTR بتبديل فوري، وضع داكن، تعدد العملات،
Header ثابت مع Mega Menu وبحث بالاقتراحات، والصفحة الرئيسية كاملة، وبيانات تجريبية (24 منتجاً).

## التشغيل
```bash
npm install
npm run dev
# افتح http://localhost:3000
```
المتطلبات: Node.js 18.17 أو أحدث. لا يلزم أي متغير بيئة في هذه المرحلة (انسخ `.env.example` إلى `.env.local` عند الحاجة).
الصور تُحمَّل من picsum.photos وتحتاج اتصالاً بالإنترنت.

## الهيكلة
- `src/app` — layout (الخطوط، اللغة، الاتجاه) و page (الرئيسية)
- `src/components/layout` — Header, Footer, Providers, AnnouncementBar, BackToTop, WhatsApp, FirstOrderPopup
- `src/components/home` — أقسام الصفحة الرئيسية
- `src/components/product` — ProductCard, QuickView, ProductSkeleton
- `src/store/useStore.ts` — اللغة، الثيم، العملة، المفضلة، السلة، المشاهدات الأخيرة (محفوظة في localStorage)
- `src/lib/i18n.ts` — قاموس الترجمة (`t(key, lang)`)
- `src/data/products.ts` — البيانات التجريبية

## ما هو وهمي حالياً (يُستبدل في المراحل القادمة)
- الـ Skeleton يحاكي التحميل بمؤقت؛ سيرتبط بقاعدة البيانات في المرحلة 2.
- السلة والمفضلة محفوظتان محلياً في المتصفح فقط؛ لا توجد صفحة سلة بعد.
- أسعار العملات بنسب ثابتة في `useStore.ts` (SAR 3.75 / AED 3.67 / EGP 48 مقابل الدولار).
- روابط الأقسام والمنتجات `#` إلى أن تُبنى صفحات المنتجات (المرحلة 2).
- نموذج النشرة البريدية يتحقق من البريد فقط ولا يحفظه.

## المرحلة 2: Supabase + صفحة المنتجات + تفاصيل المنتج

**الصفحات الجديدة**
- `/products` (و`/products?category=women`): شبكة المنتجات، فلاتر (قسم، سعر min/max، مقاس، لون، علامة، تقييم، مخفّض فقط، متوفر فقط)، 5 أنواع ترتيب، Pagination (12 في الصفحة)، ودرج فلاتر للجوال.
- `/product/p01`: معرض صور بـ Zoom وThumbnails، ألوان ومقاسات، دليل المقاسات، الكمية، إضافة للسلة / اشترِ الآن، تقدير الشحن حسب المدينة، المراجعات بالفلترة والتوزيع، الأسئلة الشائعة، مشاركة، ومنتجات مشابهة.

**ربط Supabase (اختياري)** — بدونه يعمل المتجر على البيانات المحلية تلقائياً.
1. أنشئ مشروعاً على supabase.com ثم شغّل `supabase/schema.sql` في SQL Editor.
2. انسخ `.env.example` إلى `.env.local` وعبّئ `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY` و`SUPABASE_SERVICE_ROLE_KEY`.
3. ارفع المنتجات: `npm install` ثم `npm run seed` (يتطلب Node 20.6+).
4. أعد تشغيل `npm run dev`.

**حدود المرحلة 2 (تُستكمل لاحقاً)**
- صفحتا `/products` و`/product/[id]` تقرآن عبر `src/lib/data.ts` (Supabase أو محلي). الصفحة الرئيسية والبحث في الهيدر ما زالا يقرآن البيانات المحلية مباشرة.
- المراجعات توضيحية ولا يمكن كتابة مراجعة بعد (تحتاج تسجيل دخول، المرحلة 3).
- "اشترِ الآن" يضيف للسلة فقط حتى تُبنى السلة والدفع (المرحلتان 3 و4).
- لا يوجد فيديو للمنتج؛ الصور 4 صور تجريبية لكل منتج.
- الوصف والمواصفات نص تجريبي عام.

## المرحلة 3: السلة + الكوبونات + المفضلة + تسجيل الدخول

- `/cart`: تعديل الكميات، حذف، حفظ للاحقاً، شريط الشحن المجاني (بعد 75$)، كوبونات، ملخص (Subtotal / Discount / Shipping / VAT 15% / Total)، واقتراحات Cross-sell.
- الكوبونات التجريبية: `WELCOME15` (15%) و`SAVE10` (10$ فوق 50$) و`FREESHIP`. تُعرَّف في `src/lib/cart.ts`.
- `/wishlist`: المنتجات المفضلة مع الإضافة للسلة.
- `/login` و`/account`: تسجيل بالبريد وكلمة المرور (وGoogle عند ضبط Supabase).

**تفعيل الدخول الحقيقي (Supabase Auth)**
1. اضبط المتغيرات في `.env.local` (كما في المرحلة 2).
2. في Supabase → Authentication → Providers: فعّل Email، وGoogle اختيارياً.
3. في Authentication → URL Configuration أضف `http://localhost:3000` (وعنوان موقعك بعد النشر) إلى Redirect URLs.

بدون Supabase يعمل **وضع تجريبي**: يُحفظ الاسم والبريد في المتصفح فقط ولا تُفحص كلمة المرور.

**الرفع إلى GitHub:** `.gitignore` يستثني `.env.local` و`node_modules` و`.next`. لا ترفع مفاتيح Supabase أبداً، خصوصاً `SUPABASE_SERVICE_ROLE_KEY`.

**حدود المرحلة 3**
- السلة والمفضلة تبحثان عن المنتج في البيانات المحلية بالـ id. فإذا أضفت منتجات جديدة في Supabase بـ ids مختلفة فلن تظهر فيهما قبل ربطهما بقاعدة البيانات في المرحلة 4.
- السلة محفوظة في المتصفح فقط (غير مرتبطة بحساب).
- زر إتمام الطلب لا يفتح صفحة بعد (المرحلة 4). الشحن 6$ ثابت، والضريبة 15% تُضاف فوق الأسعار.
